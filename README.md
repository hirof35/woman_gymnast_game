Team Gymnastics: Vault Championship女子体操の「跳馬（Vault）」をテーマにした、2Dアクションゲームです。6人の選手から一人を選び、助走のスピードを溜めて華麗な空中演技と着地を目指します。📋 セットアップ方法このゲームを正しく動作させるには、画像ファイルを適切な名前で配置する必要があります。1. 画像の配置プログラム（.javaファイル）と同じフォルダ、または src/ フォルダの中に、以下の名前で画像を計 24枚 配置してください。静止画（メニュー・起立時）: image_0.png ～ image_5.png走行アニメ 1: image_0_run1.png ～ image_5_run1.png走行アニメ 2: image_0_run2.png ～ image_5_run2.png空中アクション: image_0_jump.png ～ image_5_jump.png注意: 画像がないスロットは、プログラムが自動的に赤いボックス（代用図形）を表示します。2. コンパイルと実行Javaがインストールされた環境で実行してください。Bashjavac ImageGymnasticsGame/ImageGymnasticsGame.java
